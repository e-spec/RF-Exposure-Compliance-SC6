# Safety Code 6 (SC6) RF Exposure Compliance Assessment

This folder is intended to hold RF exposure compliance assessment materials, documentation, checklists, and supporting references for Safety Code 6 (SC6) reviews.

## Contents

- Site assessment notes
- RF exposure calculations
- Compliance review summaries
- Mitigation recommendations
- Supporting drawings and references

## Purpose

Use this area to organize the information needed to evaluate whether a cellular or wireless site remains compliant with applicable RF exposure limits under Safety Code 6.
